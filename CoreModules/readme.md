## Core Modules
```
Core modules are built in modules provided by NodeJs

meaning you can use them just after installing NodeJS

NODEJS is basically a tool from which we can run Javascript files directly in our terminal or server without jumping to the browser
use command => node <file-name>.js 

-> Few Examples-
1. os - cpu,memory, hostname , home directory info
2. path - cross platform file path operations ( join, resolve, extname)
3. fs - read, write , delete files and directories - sync and async
4. dns - resolve domain name to IP adresses and DNS records
5. crypto - hosting , HMAC, encryption, random bytes, tokens
6. http - create servers with http.createServer and make http requests
```
